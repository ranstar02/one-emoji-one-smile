A tiny program that writes one warm emoji — 🤗 (Hugging Face) — to `/output/entry.txt`, the single emoji most likely to make a stranger smile. A smiling face with open arms reads as kind and friendly at a glance, in any language and at any age.

## Run it

```sh
python3 main.py
```
